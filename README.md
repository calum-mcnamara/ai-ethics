# Foundations of Artificial Intelligence Ethics

Public course website for *Foundations of Artificial Intelligence Ethics* at
Indiana University.

## Updating the site

The site uses plain HTML and CSS so that it can be hosted directly with GitHub
Pages. Course text and schedule entries live in `index.html`; visual styling
lives in `styles.css`.

To publish, open the repository settings on GitHub, choose **Pages**, and set
the source to **Deploy from a branch**, using the `main` branch and the root
folder.
